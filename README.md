# Security policy root

This public repository is the intentional technical trust root for changes to
`KiloAlpha021/security-workflows`. It contains only nonsensitive policy logic,
synthetic fixtures and adversarial tests. It contains no trading implementation,
credentials, trading dependency lock or production authority.

Normal changes require a protected pull request and explicit organization-owner
approval. The organization owner and GitHub organization controls are the final
administrative root; this repository does not claim circular self-assurance.
